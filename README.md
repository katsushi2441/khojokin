# Kurage 補助金ナビ（khojokin）

会社の**地域・業種・従業員数・やりたいこと**を選ぶと、いま応募できる補助金と、
**補助率・上限額・締切・公式ページ**が出ます。

```bash
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 18360
```

## どこから取っているか

デジタル庁が運営する補助金申請システム「**Jグランツ**」の公開API
（`https://api.jgrants-portal.go.jp/exp/v1/public/subsidies`）です。
利用申請も認証も要りません。

出典：Jグランツ（https://www.jgrants-portal.go.jp）

## 規約から来ている設計上の約束（変えないこと）

API利用規約（https://fs2.jgrants-portal.go.jp/API利用規約.pdf）に従い、次を守ります。

| 規約 | この道具での扱い |
|---|---|
| 第5条1 出典表示 | 全ページの下に「出典：Jグランツ」と、加工した旨の定型文を出す |
| 第5条2 第三者の権利 | **公募要領・交付要綱の本文を持たない。** リンクだけを出す |
| 第5条5二 大量アクセス禁止 | **画面からAPIを叩かない。** 日次でまとめて取り込む。呼び出しは0.5秒間隔（上限は10回/秒） |
| 第5条5四ハ 事実に反する内容の禁止 | **補助率・上限額・締切をAIに書かせない。** 取り込んだ値をそのまま出す。絞り込みもPythonの条件一致だけ |
| 第7条2 ベータ版・予告なく停止 | 取り込んだものを手元のSQLiteに持ち、APIが落ちても画面は出る |

## 使い方

```bash
python3 scripts/fetch_jgrants.py              # 受付中を全部
python3 scripts/fetch_jgrants.py --area 愛知県
python3 scripts/fetch_jgrants.py --all        # 受付終了も含める
```

日次更新は `scripts/khojokin_jobs.py` の `update_hojokin_job()`（kdeck から呼ぶ）。
**取り込みに失敗したら古いDBを残します。** 落ちた日に画面が空になるほうが困るためです。

## 画面

| URL | 何 |
|---|---|
| `/` | 条件で絞る。地域を選んだら**地元のものを先に出す** |
| `/s/<id>` | 補助率・上限・受付期間・対象業種・公式リンク |
| `/about` | 出典と、書いていないこと |
| `/api/subsidies` | JSON（出典と注記つき） |
| `/health` | 収録件数と取り込み日 |

## この道具がしないこと

- **該当するかどうかの判定はしません。** 条件に当たりうるものを機械的に絞るだけです。
- **申請書類は作りません。** 様式は補助金ごとに違い、中身は事業計画そのものです。
- **助成金は一部しか入りません。** 厚労省の雇用関係助成金はjGrantsに載っているものだけです
  （業務改善助成金のように載っているものもあります）。別経路の取り込みが要ります。
- 自治体によってjGrantsへの載せ方に差があります。載っていない制度は入りません。

個人向けの制度は [Kurage 制度ナビ（kseido）](https://kurage.exbridge.jp/kseido.php/) にあります。
